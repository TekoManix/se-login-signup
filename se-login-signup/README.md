# SE Login & Signup

A simple login and signup web application built with HTML and CSS for ICSI 418Y Software Engineering – Homework Assignment 1.

## Project Structure

```
se-login-signup/
  login.html    - Login page with User ID and Password fields
  signup.html   - Signup page with First Name, Last Name, User ID, and Password fields
  styles.css    - Shared stylesheet for both pages
  README.md     - This file
```

## How to Use

Open `login.html` or `signup.html` in a web browser. Each page links to the other.

## Features

- Centered, card-style form layout
- Consistent styling across both pages
- No external frameworks used
